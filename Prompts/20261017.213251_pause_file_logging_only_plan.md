# User Prompt
when there is no movement, the logging is paused.
The pausing should be for writing to file only. It should not be pausing GPS location activity

# Implementation Plan - Pause File Logging Only on Inactivity / Pause

## Background & Problem
1. When there is no movement (consecutive GPS fixes within the distance threshold in Intelligent Tracking), `LocationService.handleNewLocation` previously exited before updating `lastLocationTimeMillis` and without recording `latestLocation`.
2. As a consequence, after 15 seconds of remaining stationary, `MainActivity` detected `System.currentTimeMillis() - lastLocationTimeMillis >= 15000` and incorrectly turned the status bar BROWN with `"Waiting for GPS..."`. Furthermore, coordinates displayed on the UI (`tvCoordinates`) froze because they were read only from `locationRecords`.
3. In `LocationService.setPaused(boolean paused)`, the service was previously calling `fusedLocationClient.removeLocationUpdates(locationCallback)`. This literally shut down the GPS location receiver upon pausing.

## Proposed Changes

### 1. `LocationService.java`
- Maintain `latestLocation` field and expose `public Location getLatestLocation()`.
- In `handleNewLocation(Location location)`:
  - ALWAYS update `latestLocation = location;` and `lastLocationTimeMillis = System.currentTimeMillis();` when a valid GPS location fix is received from `FusedLocationProviderClient`.
  - If `isPaused` is true, log and return early so the fix is not added to `locationRecords` (pausing file logging only).
  - If Intelligent Tracking is active and distance from last record < threshold, log and return early so the fix is not added to `locationRecords` (pausing file logging only).
  - Otherwise, add to `locationRecords` as normal.
- In `setPaused(boolean paused)`:
  - Do NOT call `fusedLocationClient.removeLocationUpdates(locationCallback)`. Keep GPS updates active so GPS location activity continues unpaused.
- In `onSharedPreferenceChanged`:
  - Allow interval updates if `isTracking` without requiring `!isPaused`.

### 2. `MainActivity.java`
- In `updateUiFromService()`:
  - Read `locationService.getLatestLocation()` to update `tvCoordinates` with live coordinates even if stationary or paused.
  - Since `lastLocationTimeMillis` is consistently updated when GPS fixes arrive, the status bar correctly stays GREEN during tracking (receiving GPS locations) instead of falsely turning BROWN ("Waiting for GPS...") when the user is stationary.
