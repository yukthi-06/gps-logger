# User Prompt

from the 'Tracks List' page when user goes to a track details, the track is shown.  Show a start and end marker.
The start marker can be a 'S' inside a circle.
The end marker can be a 'E' inside a circle.

---

## Implementation Plan

### Goal
Add a Start ('S') and End ('E') marker on the MapActivity track view, rendered as labeled circles on top of the track polyline.

### Approach
Use MapLibre's **GeoJSON Source + Symbol Layer** API to place circle-backed text symbols.
- A `CircleManager` (from the annotation plugin) draws a filled colored circle at the start and end points.
- A `SymbolManager` (from the same annotation plugin) overlays the letters 'S' and 'E' in white text on top of the circles.

### Files Changed
- `app/src/main/java/com/example/gpslocationlogger/MapActivity.java`
  - Import `SymbolManager`, `SymbolOptions`
  - In `loadTrackData()`, after drawing the polyline, add start/end circles and text symbols
  - Green circle with 'S' for start point; Red/Dark circle with 'E' for end point

### Visual Design
- Start marker: Green (#388E3C) filled circle, white 'S' text, bold, size 14sp
- End marker: Dark Red (#B71C1C) filled circle, white 'E' text, bold, size 14sp
- White stroke around circles for contrast against map tiles
