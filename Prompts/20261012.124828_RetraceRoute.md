# User Prompt

Add a button at the bottom of the track view screen for 'Re-trace this route' functionality.
When user clicks on this button, it goes into a navigation type of mode.
ie.. the user's current location is shown on the screen, along with the existing track.. the user can then drive his vehicle by following the track

---

## Implementation Plan

### Goal
Add a "Re-trace this Route" button at the bottom of MapActivity.
When pressed, enter a navigation/retrace mode:
- The saved track polyline stays on the map
- User's live GPS location is shown as a moving dot (cyan circle)
- Camera follows the user's current location automatically
- A "Stop Navigation" button replaces the retrace button to exit mode

### Files Changed
1. `app/src/main/res/layout/activity_map.xml`
   - Add `btnRetraceRoute` button at bottom of FrameLayout overlay
   - Add `btnStopNavigation` button (initially GONE, shown in retrace mode)

2. `app/src/main/java/com/example/gpslocationlogger/MapActivity.java`
   - Store parsed `trackPoints` as a field (List<LatLng>)
   - Store `mapLibreMap` and `mapStyle` as fields for reuse in retrace mode
   - Add FusedLocationProviderClient + LocationCallback for live GPS updates
   - `startRetraceMode()`: request location updates, show live dot, follow camera
   - `stopRetraceMode()`: stop location updates, remove live dot, restore UI
   - Permission check before entering retrace mode

### UX Design
- "Re-trace this Route" button: prominent blue/teal at bottom, full-width, with navigation icon
- In retrace mode: top toolbar tint changes (to signal active mode), live dot = cyan
- Camera auto-follows with zoom 17, bearing 0 (north up; user can pan freely)
