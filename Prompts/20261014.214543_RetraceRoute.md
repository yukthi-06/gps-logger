# User Prompt

Add a button at the bottom of the track view screen for 'Re-trace this route' functionality.
When user clicks on this button, it goes into a navigation type of mode.
ie.. the user's current location is shown on the screen, along with the existing track.. the user can then drive his vehicle by following the track

---

## Implementation Details

### 1. UI Components (`app/src/main/res/layout/activity_map.xml`)
- **"Re-trace this Route" Button (`btnRetraceRoute`)**:
  - Located at the bottom of the track view screen.
  - Styled with modern pill-shaped rounded corners and ripple effect ([`bg_btn_retrace.xml`](file:///x:/Projects_X/0_Active/8_Android_APK/01_GPS/GPS_Location_Logger_APK_GITHUB/app/src/main/res/drawable/bg_btn_retrace.xml)).
  - Shows location crosshairs icon and bold text.
- **"Stop Navigation" Button (`btnStopNavigation`)**:
  - Replaces the re-trace button when navigation mode is activated.
  - Styled with crimson red rounded pill shape ([`bg_btn_stop_nav.xml`](file:///x:/Projects_X/0_Active/8_Android_APK/01_GPS/GPS_Location_Logger_APK_GITHUB/app/src/main/res/drawable/bg_btn_stop_nav.xml)).
  - Allows the user to exit navigation mode cleanly at any point.
- **Active Navigation Indicator Bar (`llNavStatus`)**:
  - Semi-transparent top bar displaying active navigation status.

### 2. Navigation Logic (`app/src/main/java/com/example/gpslocationlogger/MapActivity.java`)
- **Permission Check**: Automatically requests fine location permission if not already granted.
- **Real-Time GPS Tracking**: Connects to `FusedLocationProviderClient` with high-accuracy updates every 1-2 seconds.
- **Immediate First Fix**: Leverages `getLastLocation()` to instantly center camera and display position without delay.
- **Live Location Marker**: Renders user's current position using a cyan circular dot (`#00BCD4`, 12dp radius, white border) via `CircleManager`.
- **Dynamic Camera Following**: Smoothly centers the camera (`zoom 17.0`) onto the user's vehicle location as they move along the track.
- **Drive-Safe Screen Wake**: Engages `FLAG_KEEP_SCREEN_ON` during navigation mode so the screen does not turn off while driving.
- **Clean Mode Exit & State Cleanup**:
  - On stopping navigation or backgrounding the activity, GPS updates are deregistered, the marker dot is removed, screen-lock is released, and the camera zooms back out to display the entire route overview.
